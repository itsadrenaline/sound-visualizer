## What's new

### The app quitting on its own on macOS 26 Tahoe

On some Macs running macOS 26 Tahoe, Sound Visualizer quit by itself a few seconds after opening. The crash report says "EXC_BREAKPOINT (SIGTRAP)" on "CrBrowserMain".

**Why:** the app is made of several programs: the main one, and helpers for the page and the graphics. This download isn't notarized by Apple yet, so macOS marks it as "quarantined". Allowing it with **Open Anyway** in System Settings lets the main program open. But on Tahoe the graphics helper can stay blocked. It then fails to start again and again, and the app gives up and quits.

**What's fixed:**

- **Offers to unblock itself:** when the app finds it's still quarantined, it asks once. **Unblock and restart** does the same as running `xattr -cr "/Applications/Sound Visualizer.app"` in Terminal, then opens the app again.
- **Draws without the helper:** while it's blocked, or if the graphics helper couldn't start last time, the app draws without the helper, so it doesn't quit.
- **Must be in Applications:** if it's running straight from the disk image or Downloads, it asks you to move it to Applications first.
- **Install steps:** the install steps on the release page now say to run the Terminal command on Tahoe, because Open Anyway alone isn't enough there.

If 1.6.6 or 1.6.7 quits on you: install 1.6.8, drag it to Applications, then either click **Unblock and restart** when it asks, or run this in Terminal before opening it:

```
xattr -cr "/Applications/Sound Visualizer.app"
```
