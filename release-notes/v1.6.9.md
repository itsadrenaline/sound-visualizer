## What's new

### Starting on Macs where the graphics helper won't run

This is a follow-up to 1.6.8. Some Macs still quit straight after opening because the app's graphics helper can't start ("GPU process isn't usable").

- If the app quits before its graphics have started, the next time it opens it draws without the graphics helper. It no longer depends on how the helper was blocked, and stays that way until the next update.
- So if it quits the first time, open it again: it should stay open from then on.
- On macOS 26 Tahoe, the Terminal step from the install instructions is still the surest fix: `xattr -cr "/Applications/Sound Visualizer.app"`.
